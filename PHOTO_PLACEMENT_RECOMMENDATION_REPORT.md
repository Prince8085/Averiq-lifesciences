## 5. Premium Presentation Styles

### 5.1 Recommended Styles (Aligned with Design System)

| Style | Where to Use | CSS/Implementation Approach |
|-------|--------------|----------------------------|
| **Full-Bleed Hero Background** | Homepage Hero (mobile), About Hero | `bg-[url(...)] bg-cover bg-center` + `.glass` content overlay |
| **Editorial Split Layout** | Homepage Hero (desktop), About Hero | `lg:grid-cols-[1.1fr_0.9fr]` with image in one column |
| **Asymmetric Grid Breaker** | Trichology Vertical Card | `lg:col-span-2` for image, `lg:col-span-1` for content |
| **Large Editorial Portrait** | Quality Page Sidebar, Contact Page | `w-full max-w-md` float-right with text wrap (`shape-outside`) |
| **Product Page Hero** | Individual Product Pages | Replace SVG `ProductVisual` with `<Image>` + gradient wash |
| **Unified Gallery** | New "Science in Action" section (optional) | `grid grid-cols-2 gap-4` + `group-hover:scale-105` |

### 5.2 Visual Treatment Rules (Non-Negotiable)

1. **Color Grading:** Apply unified **"Clinical Cool"** LUT — slight blue push in shadows, green lift in midtones to match brand gradient
2. **Frosted Glass Overlays:** All text on images uses `.glass` (`bg-white/85 backdrop-blur-md`)
3. **Gradient Scrims:** Bottom/top fade overlays using `bg-gradient-to-t from-primary-950/80 to-transparent`
4. **No Raw Edges:** All images in cards/containers use `rounded-2xl` or `rounded-3xl`
5. **Hover Motion:** `transition-transform duration-500 hover:scale-[1.02]` on editorial images
6. **Loading:** `blur-up` technique — show 20px blurred placeholder while loading

### 5.3 What NOT to Do

| ❌ Avoid | ✅ Instead |
|----------|------------|
| Carousels/sliders on hero | Static hero with responsive image swap |
| Masonry/Pinterest grids | Clean CSS Grid with defined ratios |
| Polaroid/frame effects | Clean rounded corners, subtle shadow |
| Heavy vignettes | Gradient scrims only where text sits |
| Watermarks/logos on images | Trust badges as separate UI elements |
| Stock photo collages | Single premium image per section |
